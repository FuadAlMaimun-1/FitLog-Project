
# 🏋️ FitLog

FitLog is a modern and responsive workout library built with Next.js. 
Users can explore workouts, view workout details, create a daily workout plan, and save workouts for later.

## 🛠️ Technologies Used

- Next.js
- React.js
- JavaScript
- Tailwind CSS
- DaisyUI
- REST API

## ✨ Key Features

- 📚 Browse and explore different workouts
- 🔎 View detailed information about each workout
- ➕ Add workouts to today's plan
- ❤️ Save workouts for later
- 📊 Track today's exercises, duration, and calories
